Hlavná databáza pre GitHub JSON
Exportuje kompletný stav (hráčov, celú históriu zápasov a parametre K/D) pod presným názvom databaza.json.
Nahraj tento súbor na GitHub do rovnakého priečinka ako HTML súbor, aby sa nové výsledky automaticky zobrazili všetkým hráčom.
Archívna lokálna záloha JSON
Uloží kompletnú kópiu databázy do PC s aktuálnym dátumom v názve súboru (napr. ELO2MASTER_v1.38_zaloha_RRRR-MM-DD.json).
Ideálne na priebežné zálohovanie sezóny pred väčšími úpravami.
Obnova zo súboru JSON Import JSON
Otvorí výber súboru v PC a načíta predtým uloženú zálohu (.json). Okamžite prepočíta tabuľku, štatistiky aj odznaky.
Pozor: Prepíše aktuálne dáta uložené v pamäti tvojho prehliadača.
Manuálny GitHub Sync Remote JSON
Okamžite stiahne najnovší súbor databaza.json zo servera (GitHubu) bez ohľadu na lokálnu vyrovnávaciu pamäť.
Použi, ak iný správca práve aktualizoval zápasy na GitHube a chceš hneď vidieť zmeny.
Export rebríčka pre Excel CSV
Vygeneruje tabuľku poradia, ELO bodov, zápasov, výhier, prehier a percentuálnej úspešnosti vo formáte .csv (oddelené bodkočiarkou).
Obsahuje kódovanie UTF-8 s BOM, takže slovenská diakritika sa v MS Excel zobrazí správne.
Zafixovať štartovaciu čiaru Sezónny štart
Vymaže históriu doterajších zápasov a nastaví novú sezónu od nuly.
Odporúčame najprv stiahnuť zálohu JSON s dátumom.
